🎲 Générateur de coffres aléatoires

Minecraft Java Edition — version cible 1.26.2 (syntaxe Data Components)
Mode d'emploi :
  1. Choisissez le type de conteneur et, si besoin, sa couleur.
  2. Cochez une ou plusieurs catégories d'objets à piocher.
  3. Cochez les options de variation aléatoire souhaitées (quantités, enchantements, durabilité, sous-conteneurs).
  4. Cliquez sur « Générer la commande », puis « Copier ».
  5. Collez la commande dans un bloc de commande (pas le chat) et activez-le.
⚠️ Cette commande est destinée à un bloc de commande. Dans le chat, elle peut dépasser la limite de caractères.
⚠️ La génération est fixe : une fois la commande générée et exécutée, le contenu du coffre ne change plus. Pour un contenu qui se renouvelle à chaque ouverture, il faut utiliser une table de butin (Loot Table) dans un datapack.
⚠️ Version cible : Minecraft Java Edition 1.26.2. La syntaxe peut différer sur d'autres versions.
